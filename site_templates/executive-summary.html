Submission checklist

  1. Use the actual generated file. Confirm that the project’s exact-file run card names the TIFF, its SHA-256, the note, and a separate selector approval. No file currently has that approval.
  2. Confirm evidence. A single-feature leakage canary, fold-local buffered holdout with CI and a comparable baseline, and both pre-placement and final-dot checks against the full registry must pass. Passing format alone is not approval.
  3. Confirm the slot. Check your account’s current capacity and the official rules. The selector—not the formatter or this page—decides whether to spend a slot.
  4. Upload. On DrivenData, sign in and enroll, open Submit → Make new submission, choose the approved single-band GeoTIFF (or a ZIP containing exactly one GeoTIFF), paste the provided short note, and submit.
  5. Keep the receipt. Record the organizer’s submission-page result, timestamp and file SHA-256. A local proxy or a forecast is not an organizer-confirmed score.

Troubleshooting

“Predicted values must be in range [0, 1]”

Do not assume a cause or clip invalid predictions. Reopen the exact downloaded bytes and check all in-footprint values are finite and within range; confirm one float32 band, CRS, shape and transform against an authenticated organizer sample. Also check exterior null/NaN and full-array range separately.

python scripts/inspect_submission.py path/to/file.tif --template path/to/organizer_sample.tif

The default template is a peer mirror, not organizer-authenticated. The diagnostic cannot authorize upload or establish that DrivenData accepts a particular exterior encoding. The public instructions specify null/NaN outside the data bounds, whereas an all-finite zero exterior only tests one possible strict range check. Ask the organizer if the discrepancy persists; no automatic resubmission is made.

Decision criteria

What “ready” means

  • Unique against every in-scope registry raster, not just a different file hash.
  • No leakage indicators; catalogue features derived only from visible faults.
  • Valid holdout improvement, not a score projection.
  • Exact TIFF passes audited checks and matches the authenticated organizer grid.
  • Independent weekly-slot selector approval.
A registry calibration lattice makes the literal 70% proximity rule impossible at the common H33-sized budget. Do not remove the control or route dots around it to manufacture a pass.
