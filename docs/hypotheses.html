Rank 1 · depth-resolved AEM basement-break / feeder test

Layers: USGS 2022–2023 airborne-electromagnetic resistivity sections/depth slices, flight-line geometry, competition grid, and competition conductivity/depth bands for lineage comparison.

Signature: a coherent lateral resistivity gradient or depth-continuous conductive corridor crossing basin fill and aligning with a basement break.

Fault rationale: a blind structure may alter the basement architecture or channel hydrothermal fluids without a surface scarp.

Named non-fault mimic: clay-rich or saline basin fill; a conductive lithologic contact; survey flight-line/inversion artifacts.

Novelty caveat: the training stack already describes conductivity and conductive-base depth. The exact AEM survey identity and incremental data content are unresolved. Do not call this new until lineage and full-registry checks show it is.

Expected HOLDOUT-DTI improvement: high qualitative prior only if the data add independent coverage; unmeasured. Cost: high—netCDF inspection, resolution/flight-line handling, co-registration, fold-local feature generation and holdout.

Official USGS AEM data release, DOI 10.5066/P1UKDJSM ↗

Rank 2 · conductive-heat-flow residuals

Layers: USGS Great Basin background conductive heat-flow map and published geothermal-well residuals, with uncertainty/support surfaces.

Signature: a spatially coherent departure from the background field near a structural boundary, tested without using catalogue geometry as a predictor.

Fault rationale: hydrothermal upflow may follow a blind permeable fault with weak surface expression; heat-flow residuals are an indirect locator, not a fault label.

Named non-fault mimic: groundwater advection, lithology, sparse well distribution or interpolation artifacts.

Novelty caveat: other GEMSDOE work already uses geothermal and thermal evidence. Compare the specific source and lineage to the full registry; do not assume novelty from a different filename.

Expected HOLDOUT-DTI improvement: moderate qualitative prior with localization uncertainty; unmeasured. Cost: medium–high—well support audit, residual interpretation, confound controls and holdout.

Official USGS heat-flow maps, DOI 10.5066/P9BZPVUC ↗

Rank 3 · earthquake focal-mechanism coherence

Layers: USGS ComCat origins and available focal-mechanism/moment-tensor strike, dip, rake, and quality/uncertainty.

Signature: spatially coherent mechanism orientations or consistent structural planes—not event density alone.

Fault rationale: subsurface seismogenic structures can be absent from a surface fault map.

Named non-fault mimic: sparse network coverage, ambiguous nodal-plane choice, or a small unrelated seismic cluster.

Novelty caveat: prior methods already include seismicity-related signals; this is only distinct if quality-controlled orientation data are actually available and improve an independent holdout.

Expected HOLDOUT-DTI improvement: low-to-moderate qualitative prior; coverage unverified. Cost: medium—API query, uncertainty handling, spatial support and feature-alone leakage check.

USGS ComCat event API ↗ · ComCat documentation ↗

Rank 4 · flightline-debiased radiometric composition edges

Layers: GeoDAWN radiometric channels, acquisition-block/flight-line metadata, terrain clearance and derived channel ratios.

Signature: a corrected, multichannel compositional boundary rather than a raw amplitude stripe.

Fault rationale: hydrothermal alteration or juxtaposed lithology can create a coherent signature along an otherwise concealed structure.

Named non-fault mimic: flightline striping, soil moisture/cover, or a non-fault lithologic contact.

Novelty caveat: simple scarp–radiometric fusion is already present in wider GEMSDOE work. Consider only a demonstrably distinct corrected feature after registry comparison.

Expected HOLDOUT-DTI improvement: low-to-moderate qualitative prior; unmeasured. Cost: medium–high—band/coverage checks, correction and confound review.

USGS GeoDAWN data release, DOI 10.5066/P93LGLVQ ↗

Rejected for this slate: fluvial chi / knickpoint morphology

The latest public GEMSDOE36 run card explicitly describes 10 m 3DEP terrain, chi/steepness and knickpoint worms. A nearby LiDAR/fluvial experiment would therefore risk duplicating a current parallel method. This is a method-level screen, not a raster uniqueness calculation.

Required first experiment, if prerequisites are restored

  1. Clarify the assigned single-method lane; do not combine methods without explicit authorization.
  2. Download authorized data and verify the shared-template hash/grid/cache and complete registry.
  3. Prove the AEM survey intersects the competition footprint and adds information beyond existing conductivity/depth bands.
  4. Freeze one feature definition; compute catalogue-based predictors from visible faults only for each buffered whole-segment fold.
  5. Test each feature alone. Investigate and stop if any AUC exceeds 0.90.
  6. Run the pinned evaluator for pooled HOLDOUT-DTI with alpha 0.2, beta 0.8, 300 m triangular kernel, withheld-positive count and 95% CI. Compare to the matched baseline.
  7. Check full-registry surface correlation before placement, then final-dot overlap; stop above the user-specified thresholds.
  8. Export/validate only after the candidate beats the comparator. Otherwise write a negative run card and produce no TIFF.
