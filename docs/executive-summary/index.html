Why the H33-2-B2 artifact is reported at 0.2778

Evidence status: OWNER-REPORT. The repository’s corrected forensic note records a nested H19-5 family: dense ridge surface → 1.5-pixel thinning → 2.8-pixel thinning → B=1 then B=2 catalogue collar pruning. It does not contain the organizer receipt that binds the reported 0.2778 to the exact file hash, so causality is not established.

The plausible metric-level explanation is that a 300 m triangular distance kernel credits nearby emitted pixels, while false-positive mass is accumulated across the prediction field. Thinning redundant adjacent ridge pixels can therefore reduce false-positive cost while preserving local coverage of hidden traces. Increasing the catalogue collar can suppress pixels that are near known faults; it can also remove useful detections. The reported score ladder alone cannot identify hidden truth, weighted TP/FP/FN, per-pixel marginal credit, or prove that B=2 caused the score change. See the corrected, evidence-limited forensic note.
