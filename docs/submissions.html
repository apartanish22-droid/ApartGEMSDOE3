Submission checklist

  1. Do not submit until a candidate beats the current holdout incumbent on the agreed spatially blocked, buffered hide-and-recover evaluator, with a paired 95% CI supporting the improvement.
  2. Run each feature-alone leakage canary; AUC above 0.90 is presumed leakage until resolved.
  3. Pass the pre-placement surface correlation and post-placement dot overlap gates against every registry raster; log a duplicate and stop on a threshold breach.
  4. Pass automated single-band GeoTIFF validation against the competition template: matching CRS, shape, transform, finite values in [0,1] across the full array.
  5. Obtain explicit separate selector authorization within the current weekly slot cap.
  6. Download the exact authorized file, submit it on the competition page, and save the organizer receipt.

These checks are independent; a format pass does not override a holdout, uniqueness, scientific-integrity, or selector failure.
