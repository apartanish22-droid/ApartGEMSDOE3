  6. Enter submission name and a short note (≤ 140 characters) recorded in the candidate's run card. Do not use an estimated score as the note.
  7. Submit and save the organizer's receipt. Record the exact file SHA-256 and receipt score as ORGANIZER-CONFIRMED.
