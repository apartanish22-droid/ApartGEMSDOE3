#1 · Catalogue-ring-aware VO-LEARN (distance-to-visible-catalogue weighting, fold-local)

proposal · not run · no slot S-RING-VOLEARN

Idea. Within each fold, weight the classifier's candidate dots by their distance to visible catalogue traces (2-3 px ring), so the top-K budget favours the ring where the holdout and the fixed-file results both concentrate.

Expected gain (unmeasured). Highest expected gain of the four, on indirect evidence. The registry records a 2-px catalogue-flank removal (H33-2, live +0.004870) in the 0.2778 family. On the fixed-file holdout, sites 24, 25, 27 and 30 score 0.093-0.097 against 0.0045 for the 0.2778 file. The hypothesis that the holdout rewards catalogue-adjacent dots is not verified. Expected gain is unmeasured.

Cost. Very low: one distance transform per fold; estimated about 5 minutes of compute.

Risk. Metric-fitting risk: the ring may score on the holdout without helping the leaderboard, which masks known faults (community thread). Must be tested against E3 paired difference.

Validation before any slot. One spatially blocked holdout run (not yet authorised). Pass if the paired difference against VO-NEAR exceeds the E3 paired difference (see the experiments table) with a CI that excludes zero.

#2 · Per-fold quantile budget instead of one global top-K

proposal · not run · no slot S-PERFOLD-QUANTILE

Idea. Replace the single global top-K with equal dots per fold cell, which reduces concentration in the highest-prevalence cells.

Expected gain (unmeasured). Medium-low: the per-cell results in E1 show uneven contributions; a balanced budget may reduce variance. Gain unmeasured.

Cost. Low: a change to the selection step only.

Risk. May lower the pooled score if the strongest cells carry real signal.

Validation before any slot. Holdout run with the same frac and NMS radius; compare pooled DTI and paired CI.

#3 · Rank-average ensemble of the HGB and logistic-regression learners

proposal · not run · no slot S-HGB-LOGREG-RANKAVG

Idea. Average within-fold ranks of the two learners before top-K selection.

Expected gain (unmeasured). Low-medium: E2 (logreg, 0.0446) was below E1 (HGB, 0.0608) at the same budget, so an ensemble may not beat HGB alone. Gain unmeasured.

Cost. Low: estimated about 2x the E1 runtime (E1 took 313 s).

Risk. Two learners double the surface for leakage review.

Validation before any slot. Holdout run; leakage canary must stay at or below 0.90 AUC for each feature.

#4 · Scarp-coherence gate on VO-LEARN candidates (existing LiDAR channels)

proposal · not run · no slot S-SCARP-GATED-VOLEARN

Idea. Keep only candidate dots where the 1 m LiDAR scarp channels (existing in the stack) show coherent step structure.

Expected gain (unmeasured). Low-medium on the 68-75% 3DEP coverage only (the registry notes 68-75% 3DEP coverage); the rest of the footprint would be unaffected or zeroed, which could cost real recall.

Cost. Medium: coverage-aware gating and a validity mask.

Risk. Coverage gaps can create artificial spatial structure, which the blocked holdout must catch.

Validation before any slot. Holdout run restricted to the 3DEP-covered domain, reported separately.
