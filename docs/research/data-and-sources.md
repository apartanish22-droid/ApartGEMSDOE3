Checked 2026-10-27. **“Available” means the linked catalog/page was viewed, not that all underlying binary data were downloaded or authenticated.** Direct shell network access in this environment is limited to GitHub and package registries; the research page-fetch tool could view the public sites below. We did not log in or bypass access controls.

## Data still needed

A single “data placement” claim is insufficient for this empty checkout. A valid run also requires the authenticated organizer example/grid, numeric training stack and labels (with provenance and permissions); a precisely assigned method lane and frozen comparison/budget policy; an up-to-date, complete registry including parallel sessions; and a genuinely comparable, fold-local current-best baseline. The exact weekly slot count and actual uploader acceptance require organizer/account access. The project cannot infer private hidden-test labels or guarantee a winning score.
