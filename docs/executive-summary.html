When a future candidate passes

Exactly how to make a submission

  1. Start here. Confirm this page explicitly identifies a newly generated file and that the automated scientific and uniqueness gates passed. A separate selector must approve a weekly slot; this research run does not make that choice.
  2. Download the exact approved artifact. Use its one-click GeoTIFF link, or its ZIP containing exactly one GeoTIFF. Compare the downloaded SHA-256 to the published run card. Do not rename or upload an older comparison archive as a new result.
  3. Check the range and grid. The official format is one float32 layer, values in [0,1], EPSG:32611 and the same resolution, bounds and transform as the official sample. The public description says data outside bounds is null/NaN. Our all-finite check is a local precaution against the reported range error, not proof of which outside-footprint encoding the portal accepts. Read the official specification ↗
  4. Open DrivenData. Sign in, enroll in the challenge if needed, choose Submit, then Make new submission. The competition requires account access; this project has not uploaded anything on the user's behalf.
  5. Select the file. Choose the approved .tif or the single-TIFF .zip. Paste the matching unique submission name where appropriate and the provided note into the optional Note field. Notes produced by this project must be at most 140 characters.
  6. Check the quota and submit. The official rules PDF states three submissions per week; the live portal is the source for current allowance and any updated rule. Submit only after the separate selector has approved the slot. Preserve the organizer's receipt, date and exact file hash—only then can a result be called ORGANIZER-CONFIRMED for that file.
  7. Final selection is separate. The official competition description says a single submission is selected for both prize rounds before the deadline. A public leaderboard result is not the private final score.
Range error? Inspect the actual rejected file for NaN, infinity, nodata sentinels and values outside [0,1] on the full array and inside the footprint. Do not silently clip invalid model outputs or assume this alone explains the portal's rejection. The shared writer and local check are documented in the repository.
Evidence boundaries

Three things a number can mean

HOLDOUT-DTI

Local proxy

Include evaluator version, withheld positives and 95% CI. It is not a live-score prediction.

ORGANIZER-CONFIRMED

Submission receipt

A score copied from a receipt bound to the exact uploaded file, not inferred from a site.

PUBLIC BOARD

Leaderboard snapshot

Official public number, date-stamped, but the board does not establish which file produced it.

USER-REPORTED

Historical claim

Given by the prompt or owner without a receipt; retained as a claim, not treated as proof.
