3. How to Make a Submission to the DrivenData DOE GEMS Competition

  1. Only after separate selector authorization: confirm a weekly slot is available and the candidate passed holdout, uniqueness, format, and leakage gates.
  2. Download the exact hash-verified GeoTIFF linked in section 1 (or the .zip mirror containing exactly one GeoTIFF).
  3. Open DrivenData DOE GEMS → New submission → upload the file.
  4. Enter the submission name and a short note (140 characters max) from the run card (e.g. H-GEO-1-CROSSGRAD-37654). Do not put an estimated score in the note.
  5. Submit and save the organizer's receipt; record the exact file SHA-256 and the receipt score as ORGANIZER-CONFIRMED.
