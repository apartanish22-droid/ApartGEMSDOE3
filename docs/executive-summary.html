What the GEMSDOE32 result suggests — and what it does not prove

The public GEMSDOE32 PR #9 describes H33-2-B2 as removing 2,545 predictions near mapped faults from a 40,199-pixel base, yielding 37,654 predicted pixels. The PR reports an internal live-mirror gain and projected score, but explicitly states that its repository did not contain an organizer receipt for any artifact. These claims explain the proposed removal mechanism; they do not independently authenticate the user-provided 0.2778.

Geologically and statistically, reducing mass near known catalogue faults can reduce uncredited predictions while preserving coverage of unmapped structures. Whether it truly improves DTI depends on withheld positives, the exact scoring mask, spatial buffering, and uncertainty. The upstream repo also documents evaluator disagreement for the historical champion; therefore the causal explanation and reproducible holdout interval remain unresolved here.

Conclusion: H33-2-B2 is the strongest user-reported historical benchmark among the nine listed sites, not a recommendation to upload that same file. A fresh candidate must beat the shared holdout baseline and pass the registry uniqueness checks before being labelled submit-ready.

Submission workflow (when a candidate clears every gate)

  1. Use the selected unique TIF download, not an older site artifact. According to the submission-form text included in the request, the portal accepts a single-band GeoTIFF or a ZIP containing one GeoTIFF; verify the current form and official format rules before upload.
  2. Run the shared portal validator: single band; expected CRS, shape, transform; predictions within [0,1]; no NaN on the footprint. Keep the validation report and SHA-256 beside the artifact.
  3. Run holdout comparison and uniqueness (candidate surface and final dots) against the complete registry. Stop on the specified correlation or overlap thresholds.
  4. On the authenticated competition submission page, select the TIF, enter its unique submission name and a note of at most 140 characters, then submit only if the run card verdict is promote.
  5. Save the submission-page receipt. Only that receipt can support an ORGANIZER-CONFIRMED score.

Current state: these steps cannot be completed because there is no validated candidate file. The next step is data/template availability and a reproducible holdout, not a submission.
