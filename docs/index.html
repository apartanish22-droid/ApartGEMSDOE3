Why we are not producing a TIFF yet

A new file must be scored using a spatially blocked hide-and-recover holdout and compared with the complete registry before it can be called high scoring or unique. The template also has to match the official CRS, shape, and geotransform; predictions must be finite on the evaluation footprint and in [0,1]. None of the inputs or shared tools required to perform those checks is present in this repository.

Safety decision: a synthetic, copied, or unvalidated raster could fail the portal's range check or duplicate an earlier submission. This page intentionally offers no TIF download until all validation gates pass.
